# Environment reference

Copying `.env.example` alone is not sufficient: run `py scripts/configure.py` to generate random local database and setup secrets. Existing `.env` files are preserved. The example contains no working credentials.

| Variable | Required? | Purpose |
| --- | --- | --- |
| `POSTGRES_PASSWORD` | Yes for Compose | Random local PostgreSQL password generated by the configure script |
| `AEGIS_COMPOSE_PROJECT` | Keep stable for an existing installation | Selects containers and persistent volumes. The current ignored `.env` pins `aegis-full-product-verify`, containing the user's existing My Space installation. Keep this value for normal startup; changing/removing it selects different database and artifact volumes |
| `POSTGRES_USER`, `POSTGRES_DB` | Defaults available | Local database role/name, both default to `aegis` |
| `DATABASE_URL` | Yes for API/worker | Injected by Compose using the PostgreSQL settings; use an explicit URL for non-Compose development |
| `REDIS_URL` | Yes for jobs | Injected by Compose; defaults to the private Redis service |
| `SETUP_TOKEN` | First-owner web setup only | Random private token required by the web setup endpoint; not an account password |
| `SESSION_TTL_HOURS` | Optional | Session duration, default 12 hours |
| `ALLOW_SELF_REGISTRATION` | Optional | `true` for local self-registration into a new private workspace; set `false` to require administrator-created accounts. Never grants existing workspace membership |
| `COOKIE_SECURE` | Optional locally | `false` for loopback HTTP; set `true` behind production TLS |
| `FRONTEND_ORIGIN` | Required to match browser origin | Exact permitted mutation origin; default `http://localhost:3000` |
| `FRONTEND_PORT`, `API_PORT` | Optional | Loopback host ports, defaults 3000/8000 |
| `API_INTERNAL_URL` | Required by frontend proxy | Private API target, normally `http://api:8000` in Compose or `http://127.0.0.1:8000` for a local Next.js process |
| `UNSW_DATA_PATH`, `IOT_DATA_PATH`, `TON_DATA_PATH`, `PHISHING_DATA_PATH` | Optional host overrides | Read-only bind-mount sources; defaults are `./data/raw/archive`, `./data/raw/archive (1)`, `./data/raw/archive (2)`, and `./data/raw/archive (3)` relative to `full-product/`. Configure creates empty directories for fresh clones. Existing `.env` overrides are preserved and must point to existing directories |
| `LOCAL_DATA_PATH` | Optional host override | Additional read-only dataset directory; defaults to `full-product/data/raw/`. Set it to an existing `global/` or other directory to register files in place |
| `DATASET_ROOTS` | Required by file services | Comma-separated allowed paths inside the API/worker container; Compose supplies the detected mounts and private upload directory |
| `STORAGE_ROOT` | Required for files | Private persistent volume path, `/storage` in Compose |
| `MAX_UPLOAD_BYTES` | Optional | File upload/import limit; example uses 50 MiB. Register larger existing CSVs by their mounted paths instead of uploading |
| `MAX_DATASET_ROWS` | Optional | Default bounded training/inspection row budget; example 50,000 |
| `WORKER_CONCURRENCY` | Optional | Standard worker process concurrency, default 1 |
| `WORKER_MAX_MEMORY_KB` | Optional | Recycle a worker child after it exceeds this memory budget; does not guarantee a hard peak-memory ceiling |
| `CODE_VERSION` | Optional | Local source version recorded with artifacts; set it to a Git SHA when available |
| `AI_PROVIDER` | Optional | `none` (default), `openai`, or `local` |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | Only for OpenAI chat | Backend-only credentials/model. Both must be supplied; no model name or live access is silently assumed |
| `LOCAL_AI_BASE_URL`, `LOCAL_AI_MODEL` | Only for local chat | Backend-configured OpenAI-compatible `/chat/completions` adapter; no local model is bundled |
| `LOCAL_AI_TIMEOUT_SECONDS`, `LOCAL_AI_MAX_TOKENS` | Optional | Local chat time/output bounds; defaults 90 seconds and 450 tokens |
| `COMPOSE_PROFILES` | Optional | `local-ai` starts the explicitly installed local-model service; leave empty for the five-service installation |
| `OLLAMA_IMAGE` | Optional | Ollama container image; this installation records its verified image digest in private configuration |
| `NVD_API_KEY` | Optional | Backend-only NVD key for the configured enrichment adapter |
| `INTEGRATION_NETWORK_ENABLED` | Optional, default `false` | Explicit outbound NVD enrichment gate; never enables asset scanning |

The UI exposes provider configuration status, not secret values. No OpenAI API key was created, reused, or written during implementation. The application starts with the assistant unconfigured. If you choose to enable an external provider later, review what authorized record context will be sent to that provider.

Changing `FRONTEND_PORT` also requires changing `FRONTEND_ORIGIN` to the exact browser origin. Use `localhost` consistently with the default configuration; `127.0.0.1` is a different web origin. `API_PORT` changes only the host-facing API port; the frontend proxy still uses private `http://api:8000` inside Compose.

Do not change the personal `.env` to run automated checks. Use a separate PowerShell terminal and explicit project such as `docker compose --project-name aegis-full-product-checks ...`, with process-only `FRONTEND_PORT=3001`, `API_PORT=8001`, and `FRONTEND_ORIGIN=http://localhost:3001`. Set `AEGIS_E2E_URL=http://localhost:3001` and `AEGIS_E2E_ISOLATED=1` in that test terminal. Never run end-to-end tests against the personal application on port 3000. A separate project has separate PostgreSQL, Redis, and artifact volumes; it does not inherit personal accounts. Close the terminal afterward to discard temporary overrides. See [local operations](OPERATIONS.md) for complete check and separate-project restore commands.
